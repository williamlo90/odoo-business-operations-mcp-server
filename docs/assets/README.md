# Portfolio visuals

`web-login.png`, `web-queue.png`, `web-receipt.png` and `web-mobile.png` are actual
Chromium screenshots from the synthetic browser acceptance run. Reproduce them
with [the browser checks](../WEB-UI.md#reproduce-browser-acceptance). These files
are not generated by the diagram renderer described below.

The original overview/architecture diagrams and CLI receipt summaries are generated by
[`deploy/render_portfolio.py`](../../deploy/render_portfolio.py). Receipt values
come from the [recorded synthetic CLI workflow](../demo/recording.json).
They are presentation graphics, not screenshots of a web application.

Run `python deploy/render_portfolio.py` with Pillow installed to regenerate the
PNGs. The renderer uses Segoe UI and Consolas on Windows, with DejaVu fallbacks;
font availability can change text rendering across machines.
