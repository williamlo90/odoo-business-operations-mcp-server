# Business skill boundary

Executable skill packages are scheduled for Phase 3. Their contracts are listed in
[REUSABLE-SKILLS.md](../REUSABLE-SKILLS.md). Phase 1 records a local research request
and reads it back; it does not execute research, AI inference or an Odoo write.

Future skill handlers call domain services, sharing authorization and transaction
rules across the assistant and worker. This file does not claim a completed skill.
