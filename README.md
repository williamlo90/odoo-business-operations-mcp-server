# Phase 0 — Odoo Business Operations MCP Server

Snapshot pembelajaran untuk scope dan perencanaan sebelum implementasi.
Disusun dari artefak Phase 0 yang tersimpan dalam commit fondasi pertama.

1. Baca [scope dan keputusan](docs/PHASE-0.md).
2. Pelajari [20 acceptance cases](docs/ACCEPTANCE-CASES.md).
3. Periksa [lingkungan awal](docs/evidence/phase0-environment.md) dan [dependency](docs/DEPENDENCIES.md).

Hasil belajar: menetapkan batas V1, memisahkan operator dan approver, menentukan
expected outcomes, serta mengidentifikasi dependency sebelum menulis aplikasi.
Belum ada aplikasi atau hasil tes pada tahap ini. Sepuluh dokumen rencana awal
diidentifikasi dalam [manifest baseline](docs/evidence/phase0-baseline.json).
Manifest tersebut merekam hash dokumen asli, bukan hash snapshot pembelajaran ini.

Lanjutkan ke tag `phase-1` untuk fondasi lokal dan `phase-2` untuk integrasi Odoo.
